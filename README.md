# MD Viewer

브라우저에서 마크다운 파일을 보기 좋게 렌더링해주는 단일 HTML 뷰어 앱.

## 사용 방법

`md-viewer.html` 파일을 브라우저(Chrome/Edge 권장)에서 직접 열면 됩니다.  
별도 서버·설치 과정 없이 바로 사용 가능합니다.

**다른 사람에게 전달할 때도 `md-viewer.html` 파일 하나만 보내면 됩니다.**  
마크다운 파서(marked.js v4)가 파일 안에 내장되어 있어 오프라인에서도 완전히 동작합니다.

## 주요 기능

| 기능 | 설명 |
|------|------|
| 파일 열기 | 상단 버튼 클릭 또는 드래그 앤 드롭 |
| 다중 탭 | 여러 `.md` 파일을 탭으로 동시 열람, 탭별 닫기 / 전체 닫기 |
| 탭 상태 복원 | 브라우저 새로고침 후에도 열람 중인 파일 자동 복원 |
| 사이드바 목차 | H1~H3 기준 자동 생성, 클릭 시 해당 섹션으로 이동, ON/OFF 토글 |
| 코드 하이라이팅 | 언어별 문법 강조 (인터넷 연결 시) |
| PDF 저장 | 현재 파일을 A4 PDF로 출력, H1마다 페이지 나눔 |

## 오프라인 동작 범위

| 기능 | 오프라인 |
|------|----------|
| 마크다운 렌더링 | ✅ 완전 동작 (marked.js 내장) |
| 코드 하이라이팅 | ❌ 인터넷 필요 (highlight.js CDN) |

코드 하이라이팅이 없어도 코드 블록 텍스트는 정상 표시됩니다.

## 기술 스택

- **마크다운 파싱:** marked.js v4.3.0 (HTML 파일 내 인라인 내장)
- **코드 하이라이팅:** [highlight.js](https://highlightjs.org/) v11 (CDN)
- **PDF 출력:** `window.print()` + CSS `@media print`
- **탭 상태 유지:** `sessionStorage`
- 단일 `.html` 파일 (CSS·JS 인라인)

## 파일 구조

```
md-viewer/
├── md-viewer.html   # 뷰어 본체 (이 파일 하나로 완결)
└── README.md
```

## 알려진 한계

- 로컬 이미지(`./img/...` 상대 경로)는 브라우저 보안 정책상 표시되지 않을 수 있습니다.
- PDF 출력은 `window.print()` 기반이므로 브라우저 인쇄 다이얼로그를 통해 저장하며, 파일명은 브라우저가 자동 지정합니다.
- 탭 상태는 같은 브라우저 탭(sessionStorage) 기준으로 유지됩니다. 브라우저 탭을 닫으면 초기화됩니다.
